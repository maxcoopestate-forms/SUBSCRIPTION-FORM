## 🚀 STEP-BY-STEP SETUP (2 Minutes!)

### STEP 1: Upload Files to GitHub

#### 1.1 Open VSCode Terminal
- Press `Ctrl + ~` (backtick) to open terminal
- Or go to **View → Terminal**

#### 1.2 Navigate to Your Repository
```bash
cd path/to/your/repository
```

#### 1.3 Add the 3 Files
Copy these files to your repository folder:
- `maxcoop-form.html`
- `maxcoop-form.css`
- `maxcoop-form.js`

#### 1.4 Commit and Push
```bash
# Check what's changed
git status

# Add the files
git add maxcoop-form.html maxcoop-form.css maxcoop-form.js

# Commit
git commit -m "Add MAXCOOP subscription form"

# Push to GitHub
git push origin main
```

*(If your branch is "master" instead of "main", use: `git push origin master`)*

---

### STEP 2: Enable GitHub Pages

1. Go to your repository on **github.com**
2. Click **Settings** tab
3. Scroll down to **Pages** (left sidebar)
4. Under **Source**, select **"main"** branch
5. Click **Save**
6. Wait 2-3 minutes

**Your form is now live at:**
```
https://yourusername.github.io/yourrepo/maxcoop-form.html
```

## 🔧 TROUBLESHOOTING

### PDF not generating
- Check browser console (F12) for errors
- Make sure jsPDF library is loading
- Try in different browser (Chrome recommended)

### Gmail not opening
- Check browser popup blocker
- Allow popups for your site
- Try clicking submit again

### PDF not downloading on desktop
- Check browser download settings
- Allow downloads from your site
- Check Downloads folder

### Share menu not appearing on mobile
- Not all phones support Web Share API
- PDF will download instead
- User can manually attach to Gmail
